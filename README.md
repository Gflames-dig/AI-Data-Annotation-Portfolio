# Annotation Guidelines

## Sentiment
- Positive: clearly satisfied or praising  
- Neutral: mixed or unclear tone  
- Negative: dissatisfaction or complaint  

## Intent
- Question: seeking information  
- Request: asking for action  
- Complaint: expressing dissatisfaction  
- Feedback: general opinion  

## Edge Cases
- Sarcasm: labeled based on implied meaning  
- Mixed sentiment: labeled as neutral  
- Strong tone: classified by intent
